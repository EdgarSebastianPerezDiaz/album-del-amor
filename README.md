# Álbum romántico

Sitio estático con HTML/CSS/JS para una experiencia romántica.

## Despliegue en Render

1. Guarda este proyecto en un repositorio GitHub.
2. En Render, crea un nuevo servicio:
   - Tipo: **Static Site**
   - Conecta tu repositorio GitHub
   - Branch: `main`
   - Root Directory: `.`
   - Build Command: deja vacío
   - Publish Directory: `.`
3. Despliega.

Si el repositorio no está en GitHub, súbelo primero y luego conéctalo desde Render.
